# Qatar Airways Flight Scraper

**Qatar Airways Flight Scraper** is an Apify Actor by Data Scrapers for Qatar Airways data.

This folder hosts the public demo GIF used on the Actor README. The scraper itself runs on Apify Store — not in this repository.

**[Qatar Airways Flight Scraper on Apify](https://apify.com/datascrapers/qatarairways-scraper)**

[![Qatar Airways Flight Scraper — input to structured data](./qatarairways-scraper-value-demo.gif)](https://apify.com/datascrapers/qatarairways-scraper)

## What this Qatar Airways scraper does

Collect Qatar Airways fares as a dataset, with flight number, duration, and total price.

Use it as a Qatar Airways scraper to extract structured data and export CSV, JSON, Excel, or XML from Apify.

## Start here

1. Open [Qatar Airways Flight Scraper](https://apify.com/datascrapers/qatarairways-scraper) on Apify Store.
2. Paste your Qatar Airways URLs, queries, or other documented inputs.
3. Click **Start** and export JSON, CSV, Excel, or XML.

If you found this GitHub page while looking for a Qatar Airways scraper, use the Apify link above to run it.
