# Instagram Email Scraper

**Instagram Email Scraper** is an Apify Actor by Data Scrapers for Instagram data.

This folder hosts the public demo GIF used on the Actor README. The scraper itself runs on Apify Store — not in this repository.

**[Instagram Email Scraper on Apify](https://apify.com/datascrapers/instagram-email-scraper)**

[![Instagram Email Scraper — input to structured data](./instagram-email-scraper-value-demo.gif)](https://apify.com/datascrapers/instagram-email-scraper)

## What this Instagram scraper does

Collect public Instagram profiles and emails listed in the biography.

Use it as a Instagram scraper to extract structured data and export CSV, JSON, Excel, or XML from Apify.

## Start here

1. Open [Instagram Email Scraper](https://apify.com/datascrapers/instagram-email-scraper) on Apify Store.
2. Paste your Instagram URLs, queries, or other documented inputs.
3. Click **Start** and export JSON, CSV, Excel, or XML.

If you found this GitHub page while looking for a Instagram scraper, use the Apify link above to run it.
