# Marktplaats.nl Scraper

**Marktplaats.nl Scraper** is an Apify Actor by Data Scrapers for Marktplaats data.

This folder hosts the public demo GIF used on the Actor README. The scraper itself runs on Apify Store — not in this repository.

**[Marktplaats.nl Scraper on Apify](https://apify.com/datascrapers/marktplaats-nl-scraper)**

[![Marktplaats.nl Scraper — input to structured data](./marktplaats-nl-scraper-value-demo.gif)](https://apify.com/datascrapers/marktplaats-nl-scraper)

## What this Marktplaats scraper does

Collect Marktplaats classified listings with price, city, and seller.

Use it as a Marktplaats scraper to extract structured data and export CSV, JSON, Excel, or XML from Apify.

## Start here

1. Open [Marktplaats.nl Scraper](https://apify.com/datascrapers/marktplaats-nl-scraper) on Apify Store.
2. Paste your Marktplaats URLs, queries, or other documented inputs.
3. Click **Start** and export JSON, CSV, Excel, or XML.

If you found this GitHub page while looking for a Marktplaats scraper, use the Apify link above to run it.
