# Facebook Groups Scraper

**Facebook Groups Scraper** is an Apify Actor by Rigel Bytes for Facebook data.

This folder hosts the public demo GIF used on the Actor README. The scraper itself runs on Apify Store — not in this repository.

**[Facebook Groups Scraper on Apify](https://apify.com/rigelbytes/facebook-groups-scraper)**

[![Facebook Groups Scraper — input to structured data](./facebook-groups-scraper-value-demo.gif)](https://apify.com/rigelbytes/facebook-groups-scraper)

## What this Facebook scraper does

Scrape public Facebook group posts into a structured dataset with authors, engagement, media links, and permalinks—no login required.

Use it as a Facebook scraper to extract structured data and export CSV, JSON, Excel, or XML from Apify.

## Start here

1. Open [Facebook Groups Scraper](https://apify.com/rigelbytes/facebook-groups-scraper) on Apify Store.
2. Paste your Facebook URLs, queries, or other documented inputs.
3. Click **Start** and export JSON, CSV, Excel, or XML.

If you found this GitHub page while looking for a Facebook scraper, use the Apify link above to run it.
