# MediaMarkt Germany Product Scraper

**MediaMarkt Germany Product Scraper** is an Apify Actor by Data Scrapers for MediaMarkt data.

This folder hosts the public demo GIF used on the Actor README. The scraper itself runs on Apify Store — not in this repository.

**[MediaMarkt Germany Product Scraper on Apify](https://apify.com/datascrapers/mediamarkt-de-scraper)**

[![MediaMarkt Germany Product Scraper — input to structured data](./mediamarkt-de-scraper-value-demo.gif)](https://apify.com/datascrapers/mediamarkt-de-scraper)

## What this MediaMarkt scraper does

Collect MediaMarkt.de products, including price, brand, and product id.

Use it as a MediaMarkt scraper to extract structured data and export CSV, JSON, Excel, or XML from Apify.

## Start here

1. Open [MediaMarkt Germany Product Scraper](https://apify.com/datascrapers/mediamarkt-de-scraper) on Apify Store.
2. Paste your MediaMarkt URLs, queries, or other documented inputs.
3. Click **Start** and export JSON, CSV, Excel, or XML.

If you found this GitHub page while looking for a MediaMarkt scraper, use the Apify link above to run it.
