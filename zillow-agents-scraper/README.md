# Zillow Agents Scraper

**Zillow Agents Scraper** is an Apify Actor by Data Scrapers for Zillow data.

This folder hosts the public demo GIF used on the Actor README. The scraper itself runs on Apify Store — not in this repository.

**[Zillow Agents Scraper on Apify](https://apify.com/datascrapers/zillow-agents-scraper)**

[![Zillow Agents Scraper — input to structured data](./zillow-agents-scraper-value-demo.gif)](https://apify.com/datascrapers/zillow-agents-scraper)

## What this Zillow scraper does

Zillow Agents Scraper returns one record per real estate agent, with phone, email, and brokerage when a detailed profile loads, for a territory contact list.

Use it as a Zillow scraper to extract structured data and export CSV, JSON, Excel, or XML from Apify.

## Start here

1. Open [Zillow Agents Scraper](https://apify.com/datascrapers/zillow-agents-scraper) on Apify Store.
2. Paste your Zillow URLs, queries, or other documented inputs.
3. Click **Start** and export JSON, CSV, Excel, or XML.

If you found this GitHub page while looking for a Zillow scraper, use the Apify link above to run it.
